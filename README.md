# مخزن توزیع و سرور به‌روزرسانی هوشمند افزونه‌ها

این مخزن به عنوان زیرساخت و سرور توزیع مستقیم به‌روزرسانی‌های اختصاصی برای افزونه‌های وردپرس عمل می‌کند.

## ساختار مخزن:

- **`raw-plugins/`**: محل قرار دادن فایل‌های زیپ خام افزونه‌ها جهت بررسی، پاکسازی و تست.
- **`updates/staging/`**: کانال آزمایشی (Staging) برای تست و بررسی سلامت افزونه‌ها روی وردپرس شخصی قبل از عرضه عمومی.
- **`updates/production/`**: کانال انتشار عمومی (Production) برای تحویل خودکار آپدیت‌ها به خریداران و سایت‌های مشتریان.
